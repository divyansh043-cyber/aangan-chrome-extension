# Aangan — Indian Art Chrome Theme (repair build 1.0.1)

Changes Chrome's actual tab strip, toolbar, and address bar to parchment/ivory with sepia text. It also supplies the Indian line-art wallpaper as a fallback for Chrome's built-in New Tab page.

## Install
1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this `aangan-chrome-ui-theme` folder (the folder containing `manifest.json`).
4. Keep the separate **Aangan — Indian Art New Tab** extension enabled for Aangan's custom layout.

Important: a Chrome theme only changes browser colours and the built-in page background; it cannot create Aangan's custom clock/search/shortcuts layout. For that layout, the Aangan New Tab extension must be enabled and be the active New Tab override.
