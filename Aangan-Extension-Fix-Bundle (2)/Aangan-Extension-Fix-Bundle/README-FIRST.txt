AANGAN FIX BUNDLE — READ THIS FIRST

The two folders do different jobs and must be loaded separately.

1) Open chrome://extensions. Turn on Developer mode.
2) Click Load unpacked and select the aangan-chrome-ui-theme folder to apply the parchment browser colours.
3) Click Load unpacked again and select the aangan-new-tab-extension folder to restore the custom Aangan page.
4) Keep both enabled. If Chrome shows the Google New Tab page, click Reload on Aangan — Indian Art New Tab, disable any other extension that replaces New Tab, then press Ctrl+T.

Do not select the outer Aangan-Extension-Fix-Bundle folder: select each named subfolder itself.
